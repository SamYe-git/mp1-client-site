# Senyu Holding Group — International Introduction Website

A responsive English-language corporate website for Senyu Holding Group, created for OIM3690 Mini Project 1.

## Client

Sam

## Project Overview

This website introduces Senyu Holding Group to potential international business partners. It presents the group’s experience in traditional Chinese medicine and health and wellness, the Senshan health product brand, and Senshan Health Town.

- Home
- Products
- Senshan Health Town
- Contact

## AI Use and Verification
The AI initially created a generic dark-green hero section for the Home page. I changed it to use an approved aerial image of the client’s Lishui base and updated the headline to “Rooted in Nature. Built for the World.” I made this change because it better represents the company’s natural origin and international brand direction.

### Responsive Navigation Review

I asked an AI coding assistant to create the initial shared navigation and mobile menu behavior. I reviewed the generated HTML, CSS, and JavaScript, then tested the navigation at a mobile screen width to confirm that the menu opens, closes, and links to each page correctly.

I accepted the output after testing it and included the final review in the commit [Final site review and accessibility fixes](https://github.com/SamYe-git/mp1-client-site/commit/91eca4d).
