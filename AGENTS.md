# Project Rules

1. Only plain HTML, CSS, and JavaScript. Never add a framework or a library.

2. Use semantic HTML and one shared external stylesheet named `styles.css` for every page.

3. Keep the same navigation and footer on all four pages: Home, Products, Where we call home, and Contact.

4. Use only approved client content. Do not use placeholder text or make unverified medical or health claims.

5. If a request needs a server, a backend, or unconfirmed client information, stop, tell me, and add it to a “Later” section in `PRD.md`.
